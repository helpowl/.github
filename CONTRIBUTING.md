# Contributing to Helpowl

Thank you for your help.

- Read the `CONTRIBUTING.md` file of the repo you want to change. It has the details for that repo.
- For a bug, open an issue with steps to reproduce it.
- For a new feature, open an issue first and wait for agreement.
- For a security problem, read [SECURITY.md](SECURITY.md). Do not open a public issue.
- All contributors sign our Contributor License Agreement. A bot asks you on your first pull request.
- Follow our [Code of Conduct](CODE_OF_CONDUCT.md).
